## 🎯 Краткая карточка проекта

* **Название проекта:** «BakeryBox» («Свежий Сюрприз»)
* **Отрасль:** FoodTech / Sustainability / E-commerce / Zero Waste
* **Форм-фактор:** Telegram Mini App (TMA) и веб-сервис онлайн-бронирования
* **Суть решения:** Реализация вечерних излишков свежей ремесленной выпечки и десертов из локальных пекарен в формате закрытых «пакетов-сюрпризов» (Mystery Bags) со скидкой 60–70% за 1–2 часа до закрытия заведения.
* **Модель монетизации:** Комиссионная (Take-Rate 22% от розничной цены бокса) + премиум-подписка на раннее бронирование (199 ₽/мес).
* **Пилотный регион:** г. Казань (с последующим масштабированием на города-миллионники РФ).
